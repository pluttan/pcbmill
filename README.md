# pcbprobe

Карта высот заготовки для фрезеровки печатных плат на станке без встроенного автоуровня.
Медь заготовки подключена ко входу щупа, фреза к общему проводу: при касании цепь
замыкается, станок запоминает Z. По сетке касаний программа платы подгоняется под рельеф.

## Порядок

1. `make probe TAP=плата.tap` — `probe.nc`: сетка ~10 мм по рабочей зоне, первое касание ставит Z0.
   Для Mach3 `DIALECT=mach3` (G31, запись M40/M41), для LinuxCNC `DIALECT=linuxcnc`.
2. Выставить X0 Y0 там же, где для платы, Z над медью 1–2 мм, прогнать `probe.nc`.
3. Сохранить лог консоли (GRBL: строки `[PRB:…]`) или файл касаний Mach3/LinuxCNC.
4. `make level TAP=плата.tap LOG=лог` — `плата_level.tap` и таблица перепада.
5. Не трогая ноль, запустить `плата_level.tap`.

Сменили фрезу — Z0 выставлять в первой точке сетки (левый нижний угол рабочей зоны),
либо `apply --ref X,Y` той точки, где выставили.

Без входа щупа: `pcbprobe.py points плата.tap` даёт шаблон CSV, Z вписать руками
(тестер в режиме прозвонки между фрезой и медью, спуск по 0.01 мм).

Ограничения: только G0/G1, дуги G2/G3 не поддерживаются.

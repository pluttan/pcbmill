# pcbmill

G-code для фрезеровки печатных плат на своём станке: из Gerber и Excellon, которые
выгружает любая EDA (KiCad, EasyEDA, Altium, Eagle), получаются программы `.tap`
в том же виде, что уже шли на этом станке: изоляция V-фрезой, наколка или сверловка
отверстий, канавка или фрезеровка по контуру. Плюс карта высот заготовки: станок
без автоуровня, поэтому рельеф снимается самой фрезой как щупом и учитывается в программе.

## Установка

```
make install
```

## Первый запуск станка

```
make selftest
```

В `selftest/` шесть пробных программ и `CHECKLIST.txt`: как узнать контроллер и его
настройки, затем по порядку оси и направления в воздухе, масштаб по линейке и пропуск шагов,
шпиндель, щуп (три касания, разброс), лесенка глубин для замера реальной ширины реза
и пары дорожек с зазорами 0.5…0.15 мм. Каждая останавливается паузой там, где нужно смотреть.

## Проверка перед запуском

Каждая программа, которую пишет pcbmill, сразу прогоняется через симулятор
(`pcbmill/verify.py`) по профилю станка. Если в ней есть опасное место, файл
переименовывается в `.BAD` и не запустится по ошибке. Чужие программы: `make check TAP=файл.tap`.

Что считается опасным: быстрый ход ниже поверхности или над самой медью, рез глубже
допустимого для операции (изоляция 0.3 мм, сверловка и контур толщина + 0.3–0.5 мм),
дюймы G20, рез при стоящем шпинделе, рабочий ход без подачи, команды, которых нет
в выбранном контроллере (M6 в GRBL, G31 вместо G38.2), щуп быстрее 100 мм/мин, вбок
или с вращающимся шпинделем, выход за ход станка и за заготовку, вложенные скобки
в комментариях, программа, которая кончается с фрезой в металле.

## Плата → программы

```
make cam GERBERS=путь/к/герберам            # односторонняя: берётся единственный слой меди
make cam GERBERS=путь SIDE=bottom          # медь снизу: зеркально, как будет лежать на столе
venv/bin/python3.12 -m pcbmill cam путь --ops iso -s isolation.depth=0.08
```

В `путь/cnc/` появятся `имя_сторона_iso.tap`, `_drill.tap`, `_cut.tap` и превью `.png`.
В консоли для каждой программы: число проходов, длина реза, примерное время и замечания.
Красные кружки на превью и строка «ВНИМАНИЕ» означают, что медь там ближе ширины реза
и фреза между ними не пройдёт; рядом подсказка, на какую глубину уменьшить рез.

Ноль программ: левый нижний угол контура платы, Z0 на поверхности меди.

## Профиль станка

`machine.toml`: диалект (grbl, mach3, linuxcnc), обороты, высоты переездов, инструменты
(V-фреза: кончик и угол; концевая: диаметр, подачи) и параметры операций. Любой параметр
меняется и с командной строки: `-s drill.mode=through -s cutout.depth=1.7`.

Ширина реза V-фрезы: кончик + 2·глубина·tan(угол/2). Для 0.1 мм / 45° на 0.1 мм это 0.18 мм.

## Карта высот

1. Медь заготовки на вход щупа, фреза на общий провод. Проверить, что станок видит касание.
2. `make probe TAP=…_iso.tap` → `probe.nc`: сетка ~10 мм, первое касание ставит Z0.
3. Выставить X0 Y0 как для платы, Z на 1–2 мм над медью, прогнать `probe.nc`, сохранить лог
   (GRBL: строки `[PRB:…]` из консоли; Mach3 и LinuxCNC пишут файл касаний сами).
4. `make level TAP=…_iso.tap LOG=лог` → таблица перепада и `…_iso_level.tap`.
   Или сразу для всех программ: `pcbmill cam путь --map heightmap.csv`.
5. Не трогая ноль, запустить выровненную программу.

После смены фрезы Z0 выставлять в первой точке сетки (левый нижний угол рабочей зоны)
или указать точку: `pcbmill apply … --ref X,Y`.

Без входа щупа: `pcbmill points …_iso.tap` даёт шаблон CSV на 20 мм, высоты вписать руками
(тестер в режиме прозвонки между фрезой и медью, спуск по 0.01 мм).

## Проверка

`make test` сначала подсовывает проверке 26 заведомо опасных программ (каждая должна
быть отвергнута) и прогоняет через неё все программы самой утилиты под тремя контроллерами
(все должны пройти). Затем гоняет примеры из `examples/gerbers` (тестовые платы библиотеки gerbonara,
Apache-2.0) через всю цепочку: программы, зеркало нижней стороны, карта высот на имитации
кривой заготовки. Проверяется, что быстрые переезды не идут ниже поверхности и все рабочие
ходы стоят на заданных глубинах.

## Ограничения

- В наложении карты на сторонние программы дуги G2/G3 не поддерживаются; свои программы
  pcbmill пишет только отрезками.
- Заливка медью целиком не снимается, обходится только её контур.
